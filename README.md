# Assets Folder

This folder is for images, audio, and other media files used across the website.

## Images

Place photo files in the `images/` folder (create it if needed).

### For the Photo Guess Game

To add real photos of Emmanuel, place them in this folder and name them:

- `photo1.jpg` - First photo
- `photo2.jpg` - Second photo
- `photo3.jpg` - Third photo
- `photo4.jpg` - Fourth photo
- `photo5.jpg` - Fifth photo

Then update the `src` paths in `js/photo-guess.js` if you use different filenames.

Supported formats: `.jpg`, `.jpeg`, `.png`, `.webp`

### Recommended Photo Specs

- Aspect ratio: 4:3 or 16:9
- Resolution: at least 800x600px
- File size: under 2MB each for fast loading

## Audio (Optional)

If you wish to add custom sound effects, place `.mp3` or `.ogg` files here and update the JavaScript files to use them instead of the generated Web Audio tones.

## Notes

- The site works perfectly without any images. Placeholder states will display helpful messages.
- All assets should be included when uploading to GitHub for GitHub Pages deployment.
